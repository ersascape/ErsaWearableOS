Detailed Description

Fixed-size event envelope with a tagged, type-specific payload union.

Creating and posting an Event copies all bounded text into the value. This lets asynchronous producers release callback-owned buffers immediately and avoids heap allocation; consumers must read only the union member associated with type because the payload storage is shared.

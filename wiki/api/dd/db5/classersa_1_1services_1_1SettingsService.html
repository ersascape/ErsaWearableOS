Detailed Description

Typed user preferences exposed independently from persistent storage format.

UI and service code use named settings rather than raw keys so defaults, validation, and future migrations remain centralized in the implementation. Setters update the service's in-memory view; save() is the explicit durable commit boundary for backends that buffer writes.

Detailed Description

BLE transport, advertising, and link-state contract.

This interface owns radio lifecycle only. Companion semantics such as calls, notifications, media, and phone time live behind ICompanionSource so another transport/provider can supply them without pretending to be this BLE stack. Driver callbacks should hand off work and avoid running UI code directly.

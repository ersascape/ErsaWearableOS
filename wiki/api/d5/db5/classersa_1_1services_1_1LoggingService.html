Detailed Description

Severity-filtered logging contract for firmware and host implementations.

The interface gives services one printf-style diagnostic sink on hardware and in tests. Backends decide where messages go (serial, ring buffer, or host output), while the severity threshold avoids constructing/forwarding routine messages when a deployment wants quieter logs.

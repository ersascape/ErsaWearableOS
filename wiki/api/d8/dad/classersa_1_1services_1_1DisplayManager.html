Detailed Description

Coalesces drawing changes and applies panel-specific refresh policy.

Apps only mark content dirty; this manager rate-limits physical refreshes and tracks partial-frame counts. E-paper drivers disable panel drive voltage after each refresh while retaining the visible image. Keeping those decisions here prevents fast UI events from causing excessive e-paper flashing or shortening panel lifetime.

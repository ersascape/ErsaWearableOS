Detailed Description

Transport-independent decoder for one ANCS notification-attribute response.

The firmware issues at most one attribute request at a time, so this parser accumulates its fragments in one bounded buffer and verifies the UID before publishing text. It knows the ANCS wire format but not GATT callbacks; that split makes malformed/truncated packet behavior testable without a radio.

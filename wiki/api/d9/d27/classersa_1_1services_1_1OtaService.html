Detailed Description

Coordinates release checks, inactive-slot image installation, and rollback safety.

Network download runs outside the UI tick. The bootloader records whether an image is pending validation; this service confirms it only after firmware startup checks pass. Keeping slot selection and confirmation here prevents app code from writing arbitrary flash addresses or bypassing rollback.

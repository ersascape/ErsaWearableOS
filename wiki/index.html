API reference

The published C++ API reference covers project headers, source, services, board support, platform HALs, peripheral drivers, and tests. Class and function pages explain their purpose, behavior, constraints, side effects, and design rationale. Build it locally with make docs; the result is api/index.html in .pio/wiki-site/. Third-party Arduino and ESP-IDF SDK sources are maintained upstream and are linked from the app-building guide rather than copied into this reference.

Contributing changes

Run make test, make firmware, and make docs for changes that affect the firmware or its interfaces. Keep board wiring in the BSP, vendor APIs in the matching platform HAL or peripheral driver, and update the relevant wiki page when behavior changes.
